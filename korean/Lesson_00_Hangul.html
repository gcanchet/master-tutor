4. Syllable Blocks

Korean characters are grouped into blocks rather than written linearly.

  • ㄴ (n) + ㅏ (a) = 나 (Na)
  • ㅎ (h) + ㅏ (a) + ㄴ (n) = 한 (Han)

5. Core Sentence Patterns

  • [Consonant] + ㅏ = [Consonant Sound] + "ah" (e.g., 바 = Ba)
  • [Consonant] + ㅣ = [Consonant Sound] + "ee" (e.g., 비 = Bi)
  • [Double Consonant] + vowel = Sharper, tense sound (e.g., 까 = Kka)

6. Common Pitfalls

The "Horizontal vs. Vertical" Bug: ㅏ faces out (right), ㅓ faces in (left). Think of ㅏ as "Ah-way".

The Silent "ㅇ" Bug: ㅇ is silent when at the start of a syllable (e.g., 아 is just "a").

The Tense Consonant Bug: Pronouncing ㄲ like a breathy k. It should be sharp and constrained.

7. Practical Dialogue: "Reading Signs"
