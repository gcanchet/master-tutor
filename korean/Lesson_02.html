Lesson 02: Actions and Objects

1. Review

In Lesson 01, you mastered Identity. Remember: 은/는 marks the topic, and 입니다 (is/am/are) is the formal copula. Example: 저는 학생입니다 (I am a student).

3. Grammar Rules

Rule A: Subject Particles (이/가)

While 은/는 marks the topic, 이/가 marks the subject performing the action.

  • 이 (i): Use after a consonant (e.g., 밥이).
  • 가 (ga): Use after a vowel (e.g., 사과가).

Rule B: Polite Present Tense (-아요/어요)

  1. If the last vowel is ㅏ or ㅗ, add -아요. (Example: 가다 -> 가요)
  2. For everything else, add -어 요. (Example: 먹다 -> 먹어요)
  3. 하다 verbs always change to 해요.

4. Core Sentence Patterns

5. Common Pitfalls

The "은/는" vs "이/가" Bug: Use 이/가 when introducing new information or describing who is doing the action right now. Use 은/는 for general topics or contrast.

6. Practical Dialogue

Describe basic actions in context:

  • "Mother goes." (어머니가 가요.)
  • "Father eats." (아버지가 먹어요.)

7. Practice

Translate the following into Korean using the polite present tense:

  1. 어머니가 가요.
  2. 아버지가 먹어요.
  3. 학생이 마셔요.
  4. 제가 해요.
  5. 선생님이 밥을 먹어요.
